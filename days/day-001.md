## The problems I want to explore

### 1. Invoice Intelligence
Read an invoice and extract the required information into structured fields.

### 2. Sustainability Classification
Suggest appropriate sustainability tags for vendor pay items.

### 3. Waste Document → Material Docket
Read a waste destination/tip-site document and transform the relevant information into a material docket upload file.

### 4. Intelligent Plant Identification
Allow a user to enter an imperfect plant identifier and determine the correct plant using available information such as:

- Plant name
- Asset ID
- LV number
- PPID
- Registration number

The system should deal with incomplete or slightly incorrect input rather than requiring an exact database match.

### 5. Plant Forever
Explore a system for plantation programs where someone photographs a newly planted tree and records its GPS location.

The photograph, location and associated information become a persistent digital record of that plant that can be referenced and revisited over time.

The idea could potentially be generalised beyond a single NGO or plantation program.

## What I learned

### GitHub

Today I created my first new GitHub project in years and started understanding the basic workflow:

**Repository → Files → Changes → Commit**

A commit creates a recorded version of a change, allowing the history of the project to be followed over time.

### GitHub fundamentals

A repository is the complete project together with its version history.

`main` is the default branch containing the current official version of the project.

A branch creates a separate line of development where changes can be made without immediately changing `main`.

A commit records a set of changes as a point in the project's history.

A pull request proposes bringing changes from one branch into another and provides an opportunity to review them.

A merge incorporates the changes from one branch into another.

### A principle for the next 100 days

The objective is not to learn AI as a collection of isolated concepts.

I want to start with real problems and learn the necessary AI concepts while trying to solve them.
